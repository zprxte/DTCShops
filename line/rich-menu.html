แท็บ DTC SHOPS ใหม่

ปุ่มแบบ “ลิงก์” เปิดเว็บค้นหาและเปรียบเทียบสินค้าของเรา ส่วนปุ่ม “ส่งข้อความ” ต้องมีบอทคอยตอบ

ปุ่มเมื่อกด

กดสินค้าแล้วเด้งคุณสมบัติ ลองกดได้

ในแท็บ DTC SHOPS ลองกด “สินค้าแนะนำ” “ค้นหาสินค้า” หรือ “หมวดหมู่สินค้า” แล้วกด “ดูคุณสมบัติ” บนการ์ด · สินค้าและสเปคเป็นข้อมูลจริงจากระบบ (ยอดเข้าชมสูงสุด 6 อันดับ)

  • การ์ดสินค้าแบบปัดได้คือ Flex Message แบบ carousel (สูงสุด 12 ใบต่อข้อความ)
  • ปุ่ม “ดูคุณสมบัติ” เป็น action postback ส่ง spec=itm-… ไปให้ backend แล้ว backend ตอบเป็นการ์ดสเปค ข้อมูลมาจาก tbl_attribute_value แหล่งเดียวกับหน้าเว็บ
  • การ์ดสเปคแสดง 8 หัวข้อแรก ที่เหลือให้กด “ดูบนเว็บ” เพราะการ์ด LINE ขยายเองไม่ได้
  • ปุ่มเลือกคำหรือเลือกหมวดใต้แชตคือ Quick Reply กดแล้วหายไปเอง
  • ค้นหาจริงใช้ /api/search ตัวเดิม พิมพ์ผิดหรือลืมสลับแป้นก็หาเจอเหมือนในเว็บ

ต่างจากเมนูเดิมตรงไหน ต้องตกลงกับทีม

  • เพิ่มแถบแท็บสูงประมาณ 14% ไว้บนสุด ปุ่มเดิมจึงเตี้ยลง แต่ภาพยังเป็น 2500 × 1686 px เท่าเดิม
  • รูปปุ่มเดิมต้องให้ทีมกราฟิกจัดวางใหม่ (ในภาพจำลองนี้ใช้ไอคอนวาดแทนรูปจริง)
  • ไม่มีปุ่ม “แจ้งซ่อม” (กด 4) ในเมนูเดิมอยู่แล้ว ผมจึงไม่ได้เพิ่ม

ถ้าจะทำจริง

  • ทำรูป 2 ภาพ ขนาด 2500 × 1686 px (ภาพละแท็บ) และวาดแถบแท็บไว้บนสุดของทั้งสองภาพ
  • สร้าง rich menu 2 ชุดผ่าน Messaging API แล้วตั้ง alias tab-gps / tab-shop
  • ตั้งพื้นที่กดของแท็บ (และปุ่ม “ดูข้อมูลผลิตภัณฑ์”) เป็น action richmenuswitch
  • ⚠️ เมนูที่ตั้งผ่าน API จะแสดงแทนเมนูที่ตั้งไว้ใน LINE OA Manager ต้องให้ผู้ดูแล OA อนุญาตก่อน
