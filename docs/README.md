## ภาพรวมระบบใน 1 นาที

**Product Search & Comparison System** คือระบบค้นหาและเปรียบเทียบสินค้าของ DTC สร้างขึ้นเพราะทีมขายจำสเปคสินค้าทุกตัวไม่ได้ และลูกค้ามักเรียกสินค้าด้วยชื่อย่อ/พิมพ์ผิด — มี 2 ฝั่ง:

- **ฝั่งผู้ใช้ทั่วไป (Public)** — ค้นหาสินค้าแบบ fuzzy search ด้วย fuse.js (พิมพ์ผิดก็หาเจอ, ค้นจากค่าสเปคได้ด้วย), autocomplete กดแล้วเข้าหน้าสินค้าเลย, "คุณหมายถึง…?" เมื่อค้นไม่เจอ, ดูสินค้าทั้งหมดพร้อมกรอง/เรียง/แบ่งหน้า, ดูรายละเอียดสินค้า (สเปคเต็ม แกลเลอรี เลือกโมเดล เลือกตัวเลือกเสริม), **เปรียบเทียบสินค้าสูงสุด 4 ช่องแบบตารางเคียงข้างกัน** (เทียบสินค้าตัวเดียวกันคนละโมเดลได้ คัดกรองด้วยฟีเจอร์ เรียงลำดับ แชร์ลิงก์), สลับภาษาได้ 3 ภาษา (ไทย/อังกฤษ/ญี่ปุ่น)
- **ฝั่งแอดมิน (Admin Panel)** — ล็อกอินด้วย JWT, แดชบอร์ดสรุปยอดเข้าชม, จัดการสินค้า/หมวดหมู่/คุณสมบัติ(สเปค)/โมเดลสินค้า/ตัวเลือกสินค้าแบบ CRUD, และจัดการเนื้อหาเว็บ (แบนเนอร์, บทความ, สาขา DTC Shop, โฆษณา, SEO, Footer) รวม 19 หน้าจอ

**Tech stack หลัก**: Vue 3 + TypeScript + Vite (frontend) ↔ Node.js + Express + Prisma (backend) ↔ PostgreSQL 16 (database) — รันทั้งหมดผ่าน Docker Compose

**ฐานข้อมูล**: ใช้ **สำเนาโครงสร้างตารางจริงของ dtcshops.com** (`tbl_item`, `tbl_item_type`, `tbl_attribute`, `tbl_attribute_value`, …) ไม่ได้ออกแบบตารางขึ้นใหม่ — เป็นสำเนาในเครื่อง ไม่ได้เชื่อมกับเว็บจริง

ดูรายละเอียดเจาะลึกต่อในแต่ละไฟล์ตามสารบัญด้านบน
