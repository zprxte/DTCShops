# Frontend (`frontend/src/`)

> อยากได้ภาพรวมทั้งระบบก่อน อ่าน [overview.md](./overview.md) — ไฟล์นี้เจาะเฉพาะโค้ดฝั่งหน้าเว็บ

SPA เขียนด้วย Vue 3 (`<script setup lang="ts">`) + Vite + Vue Router 4 + Pinia + Tailwind CSS

## จุดเริ่มต้น

- [`main.ts`](../frontend/src/main.ts) — `createApp(App).use(createPinia()).use(router).mount('#app')`
- [`App.vue`](../frontend/src/App.vue) — root component แค่ render `<ToastContainer />` (แสดง toast ทับทุกหน้า) กับ `<router-view />`
- [`router/index.ts`](../frontend/src/router/index.ts) — route table ทั้งหมด (ดูด้านล่าง)

`/admin/login` อยู่นอก `AdminLayout` (ไม่มี sidebar) — เส้นทางที่ไม่รู้จักทั้งหมด (`/:pathMatch(.*)*`) redirect กลับ `/`

**ตำแหน่งเลื่อนหน้า (`scrollBehavior`)** (11 ก.ย. 2026) — เปลี่ยน path = กลับบนสุด (เดิมไม่ได้ตั้งไว้ กดการ์ดหมวดหมู่ที่อยู่ค่อนล่างของหน้าแรกแล้วหน้าสินค้าเปิดมาอยู่ท้ายรายการ), path เดิมแต่ query เปลี่ยน เช่นติ๊กชิปตัวกรอง = ไม่เลื่อน, ปุ่มย้อนกลับ/ไปข้างหน้า = คืนตำแหน่งเดิมหลังรอความสูงหน้าไม่เปลี่ยน 400ms (สูงสุด 2.5 วินาที) — ถ้าคืนก่อนหน้าแรกโหลดแบนเนอร์/หมวดหมู่เสร็จ scroll anchoring ของเบราว์เซอร์จะดันเลยตำแหน่งเดิมไปมาก

**ชื่อแท็บเบราว์เซอร์** (11 ก.ย. 2026) — แต่ละ route มี meta `titleKey` (Public, แปลผ่าน `langs()`) หรือ `title` (แอดมิน, ไทยล้วน) ประกาศ type ไว้ใน `RouteMeta` ต้นไฟล์; `composables/usePageTitle.ts` (เรียกใน `App.vue`) ตั้ง `document.title` เป็น `"<ชื่อหน้า> | DTC SHOP"` หรือ `"| DTC Admin"` และเปลี่ยนตามภาษาทันที; หน้าผลค้นหาใช้ `ผลการค้นหา "<คำค้น>"`; หน้าที่ชื่อขึ้นกับข้อมูลตั้ง `pageTitleOverride` เอง (ตอนนี้มีแค่ `ProductDetailPage.vue` = ชื่อสินค้า) ซึ่งถูกล้างอัตโนมัติเมื่อเปลี่ยน path — เพิ่ม route ใหม่ต้องใส่ `meta.title`/`titleKey` ด้วย ไม่งั้นแท็บจะขึ้นแค่ชื่อแบรนด์

**Auth guard**: `router.beforeEach()` เช็ค `to.meta.requiresAuth` — ถ้าต้อง auth และ `useAuthStore().isAuthenticated` เป็น false จะ redirect ไป `admin-login` ทันที (แทนที่ `<ProtectedRoute>` component แบบที่ React เคยใช้)

## Layouts

### `components/layouts/PublicLayout.vue`
โครง: แถบภาษา/ลิงก์แอดมินด้านบนสุด (ไม่ sticky, เลื่อนหายไปตามปกติ) → header (โลโก้ + nav + `SearchAutocomplete`, `sticky top-0`) → `<router-view />`

> **ช่องค้นหาแสดงทุกขนาดจอ (16 ก.ย. 2026)** — อยู่แถวเดียวกับโลโก้เสมอ (`flex-1 min-w-0 max-w-md ml-auto`) เดิมเป็น `hidden sm:block` แล้วมีช่องซ้ำอีกตัวในเมนูแฮมเบอร์เกอร์ ทำให้มือถือต้องกด 2 ครั้งกว่าจะค้นได้ ตอนนี้เหลือช่องเดียวทั้ง header · `min-w-0` ห้ามเอาออก: flex item ที่มี `<input>` ข้างในมีความกว้างขั้นต่ำตามธรรมชาติของ input ถ้าไม่ปลดจะหดไม่ลงและดัน header ล้นขอบจอบนมือถือ · ความกว้างจริงที่วัดได้: 218px ที่จอ 360px · 248px ที่ 390px · 448px ที่ 1280px → ปุ่มลอยตะกร้าเปรียบเทียบ → footer — header วัดความสูงจริงของตัวเอง (`ResizeObserver`, resync ตอนเปิด/ปิดเมนูมือถือด้วย) แล้วประกาศเป็น CSS var `--sticky-header-h` บน `<html>` ให้หน้าอื่นที่มี sticky ของตัวเองใต้ header (เช่น `ComparePage.vue`) offset ตามได้แม่นยำแทนใช้ค่าคงที่ตายตัว — **ปุ่มลอยตะกร้าเปรียบเทียบ (เปลี่ยนจากแถบ sticky เต็มความกว้างเดิม 4 ก.ย. 2026)**: ปุ่มวงกลมลอยมุมขวาล่าง (`fixed bottom-5 right-5`) มีไอคอน `GitCompare` + badge ตัวเลขนับจำนวนสินค้าในตะกร้า (ซ่อน badge ถ้าตะกร้าว่าง) กดแล้วไปหน้า `/compare` — โชว์ตลอดทุกหน้ายกเว้นตอนอยู่ที่ `/compare` เอง (ไม่ขึ้นกับว่าตะกร้ามีสินค้าหรือไม่)

### `components/layouts/AdminLayout.vue`
Sidebar navigation ฝั่งซ้าย (เมนูภาษาไทยล้วน) + `<router-view />` ฝั่งขวา ปุ่ม "ออกจากระบบ" เรียก `authStore.logout()` แล้ว redirect ไปหน้าแรก (`/`) — ใช้ `h-screen overflow-hidden` ที่ container นอกให้เฉพาะพื้นที่เนื้อหา scroll เอง กันปุ่ม logout หลุดจากจอเวลาตารางยาว

## Accessibility (Week 14, 10 ก.ย. 2026)

ตรวจด้วย **axe-core ผ่าน Playwright จริง** ทั้ง 5 หน้า public + 3 หน้า admin — ปัจจุบัน **0 violations** ทุกหน้า รวม `AdminLoginPage.vue` (11 ก.ย. 2026 ปลดล็อกแล้วแก้: ปุ่มเข้าสู่ระบบ `bg-brand-600`→`bg-brand-700` ให้ contrast ถึง 4.5:1 และครอบเนื้อหาด้วย `<main>` เพราะหน้านี้อยู่นอก layout)

สิ่งที่แก้ไปในรอบนี้:
- **สีตัวอักษร/พื้นหลัง (contrast)** — `text-gray-400` (2.54:1) → `gray-500` (4.83:1), ตัวอักษรเล็กสี `text-brand-600` (3.43:1) → `brand-700` (4.97:1) โดยคงหัวข้อตัวใหญ่ไว้ที่ brand-600 (ตัวใหญ่ใช้เกณฑ์ 3:1), ปุ่มพื้นทึบตัวอักษรขาว `bg-brand-600`/`bg-accent-500` → `brand-700`/`accent-700`, `text-red-500` → `red-600`, เมนูแอดมินที่เลือกอยู่ `bg-brand-500` → `brand-700`
- **ปุ่มไอคอนล้วน** — ใส่ `aria-label` ให้ครบ (ปุ่มเพิ่ม/ลดจำนวนในหน้าสินค้าไม่มีชื่อให้อ่านเลย = critical) และใส่ `aria-hidden="true"` ให้ไอคอน lucide ทั้ง 115 จุด (ไอคอนเป็นภาพประกอบเสมอ ข้อความ/aria-label อยู่ที่ปุ่มแล้ว)
- **โครงสร้างหน้า** — ลิงก์ "ข้ามไปยังเนื้อหาหลัก" (โผล่เมื่อกด Tab) + `id="main-content"` ที่ `<main>`, เพิ่ม `<h1>` (sr-only) ให้หน้าแรก/หน้าเปรียบเทียบ (ต้องวางไว้**นอก**กล่อง `space-y-*` ของหน้า — `sr-only` ไม่กินพื้นที่ แต่ยังนับเป็นลูกคนแรกของ `space-y` ทำให้เนื้อหาถัดไปโดน `margin-top` ดันลงมา), `<h2>` sr-only คั่นก่อนกริดสินค้า (กันลำดับหัวข้อข้ามขั้น h1→h3), แถบบนสุดห่อเป็น `<nav aria-label>` และปุ่มลอยเปรียบเทียบห่อเป็น `<nav>` (เดิมอยู่นอก landmark ทั้งคู่), `<nav>` ในหน้าแอดมินมีชื่อกำกับแยกกัน
- **ป็อปอัป/ข้อความแจ้งเตือน** — ป็อปอัปเลือกสินค้าใน `ComparePage.vue` เพิ่ม `role="dialog"`/`aria-modal`/`aria-labelledby` + ปิดด้วย Esc, `ToastContainer.vue` เพิ่ม `role="status"`/`aria-live="polite"` (เดิมโปรแกรมอ่านหน้าจอไม่รู้เลยว่ามีข้อความเด้ง), ปุ่มเปรียบเทียบบนการ์ดใส่ `aria-pressed`
- **รูปภาพ** — `alt=""` สำหรับรูปที่มีข้อความกำกับอยู่ข้างๆ อยู่แล้ว (axe: image-redundant-alt)
